Notes

What's substituted, approximated, or pending — flagged openly so anyone working with this repo knows the gaps between this and the canonical brand system.

Typography substitution

Production Valtech work uses two typefaces — Valtech Neue (custom commission from Folch Studios) for display, and Söhne (Klim Type Foundry) for functional text. Neither is licensable for use in a public repository.

This repo uses Inter from Google Fonts as a placeholder for both roles. Inter is the closest open-source approximation of Söhne and shares its neo-grotesque foundations. The visible difference between display and functional type that exists in production is therefore not present here.

When this work moves into a Valtech-hosted environment with the licensed font files available, the substitution is two @font-face blocks and the --font-display and --font-functional token values.

Colour values

Hex codes were extracted from screenshots of valtech.com and the brand expression mood board. They're within roughly 3-5% of the canonical values but should be treated as approximate until confirmed against the brand portal.

The four anchor colours — cream, ink, indigo, spark — are visually accurate. Coral and the ink scale (soft, muted) are best estimates. Sub-token values like rule colours are derived rather than measured.

To correct any value, edit the relevant CSS custom property in styles.css. Every page in the repo references the same tokens.
